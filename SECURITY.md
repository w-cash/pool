# Wcash pool security policy

This repository is pre-testnet software. It has not completed an independent
security audit and must not be used with funds of real value.

Report security-sensitive issues through GitHub's private
[vulnerability-reporting flow](https://github.com/w-cash/pool/security/advisories/new).
Do not publish suspected remote compromise, payout theft, share-accounting,
denial-of-service, or consensus-adjacent vulnerabilities in a public issue.

Include the affected commit, deployment topology, impact, reproduction steps,
and the smallest practical proof of concept. Public, non-sensitive defects can
be filed in the [issue tracker](https://github.com/w-cash/pool/issues).
