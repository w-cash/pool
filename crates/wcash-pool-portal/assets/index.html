Add a separate Testnet destination for each chain. Each new or changed destination has a 48-hour safety hold; the exact release time appears after saving. Rewards continue to accumulate while payouts are held.

Wcash Testnet requires an Ironwood-capable Unified Address. Zcash addresses and other receiver types are not accepted.
